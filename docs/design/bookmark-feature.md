# 产品设计：收藏（书签）功能

状态：设计稿 v1 · 2026-10-08
一句话：**把微信里看到的好文章，变成人脉的一部分**——存链接、AI 总结、关联到人。

---

## 1. 定位

**收藏不是新的独立模块，是笔记的快捷形态**（一条带 url 的笔记）。

- 不加底部导航 tab（5 个已满），收藏住在「笔记」里，列表加"🔗 链接"筛选
- 用户话术叫「收藏」，系统内部就是笔记——不引入新实体类型，同步/图谱/全文检索全部免费复用
- 差异化不在"存链接"（微信收藏/Cubox 都是），在 **文章 × 人脉**：文章可以关联到联系人，见面前有话聊、转发有由头

**这个功能对产品的战略意义**：见人是一周几次，看文章是每天。收藏给织遇补上"每天打开"的频率钩子（对应推广期最缺的留存）。

## 2. 用户场景

| # | 场景 | 流程 |
|---|---|---|
| A | 微信里看到好文章 | 复制链接 → 切到织遇 → 输入栏自动识别 → 一键收藏（AI 总结自动完成） |
| B | 谈资储备 | 见张三前打开他的详情 → "存过 2 篇相关文章" → 转发当开场白 |
| C | 回访钩子 | 收藏时关联了李四 → 久未联系提醒时带着文章问候 |
| D | 月度回顾 | 本月收藏 14 篇，行业趋势一目了然（远期：月报素材） |

## 3. 核心流程（MVP = 场景 A）

```
快捷输入栏粘贴 URL
  → 识别为链接 → 输入卡变为「收藏模式」
  → 显示抓取状态：⏳ 抓取中… → ✅ 文章标题 + 域名
  → 用户可（可选）点选关联联系人
  → 点保存 → 立即入库（不等待 AI）
  → AI 总结后台完成 → 回填摘要（详情页可见）
```

**三条产品铁律**：
1. **保存不等待 AI**——网络/抓取/总结任何一环失败，链接都已在库里。总结是锦上添花
2. **总结失败静默降级**——详情页显示"总结未生成 · 点重试"，绝不报错打扰
3. **URL 优先**——输入内容含链接时，快捷输入直接进收藏模式，不走普通分类

## 4. AI 总结的产品规则

- **格式**（为"人脉管家"人设服务，不做阅读器式全文摘要）：
  ```
  【3 句话以内】这篇文章讲什么、为什么值得存
  【要点】≤3 条，每条一行
  【关联建议】文中提到的人名/公司，匹配到已有联系人则建议关联
  ```
- **降级链**：全文抓取成功 → LLM 总结；抓取只拿到标题 → 只存标题（标记"未总结"）；完全失败 → 存链接本身
- **无 LLM Key 时**：功能照常，只是没有总结（不阻塞发布，Key 后配）
- **成本**：每篇几百 token，M3.1-Flash 级模型单篇 <1 分钱；不做用户级限额（自有服务器，量小）

## 5. 交互细节

- **输入栏**：placeholder 轮换语加一条"粘贴链接，收藏好文章"
- **收藏模式卡**：识别到 URL 后，分类徽章显示「🔗 收藏」，下方展示抓取到的标题预览（抓取中显示骨架屏），关联联系人选择器同现有交互
- **详情页**：链接卡片置顶——favicon + 标题 + 域名 + AI 摘要块 + 「阅读原文」按钮（浏览器打开）
- **列表**：带链接的笔记显示域名角标（mp.weixin.qq.com）；筛选条新增「🔗 链接」
- **图谱**：收藏作为笔记节点正常出现（免费）
- **空状态**：笔记列表筛选为空时引导"在微信里复制一篇文章链接，粘贴到首页试试"

## 6. 数据与同步（概要）

- `note` 表新增两列：`url TEXT`、`summary TEXT`——PG 与桌面 SQLite 同步加列
- 复用现有 entity_links 关联联系人；复用 LWW 同步（新列随行数据走）
- 总结回填 = 笔记 update，同步照常

## 7. 分期

| 期 | 内容 | 触发条件 |
|---|---|---|
| **V1（本次）** | 快捷输入识别 URL / 服务端抓取+总结（可降级）/ 详情链接卡 / 列表筛选 | 直接做 |
| **V2** | **Android 分享面板**："分享给织遇"直达收藏（CI 已有 manifest patch 通道，加 intent-filter） | V1 上线且自用顺畅 |
| **V3** | 按人聚合的文章视图；"这篇适合发给谁"推荐；月度收藏报告（可做小红书素材，接上"晒"的传播线） | 数据证明需求 |
| 不做 | iOS 分享扩展（Tauri 不支持，成本高）；全文存档/离线阅读（是阅读器，不是织遇） | — |

## 8. 成功指标

- 收藏数/周（激活频率钩子）
- 关联到联系人的收藏占比（差异化是否成立，目标 >40%）
- 总结成功率 >85%，抓取失败率 <10%
- 收藏用户次月留存 vs 非收藏用户（验证"日常打开"假设）

## 9. 待定决策（默认值已选，可改）

| 决策 | 默认 | 备选 |
|---|---|---|
| 用户话术 | 收藏 | 剪藏 / 书签 |
| 总结形态 | 3 句 + 要点 + 关联建议 | 一句话 / 要点式 |
| 关联人 | 保存时手动选 + 总结后建议 | 仅手动 |
| LLM | 服务端配 Key（OpenAI 兼容协议，默认 minimax） | BYOK 客户端直连（后续） |
