### Voice AI 最佳实践

行业共识（Zoye / BlaBlaNote / Demodesk 博客）：
- **确认步骤 > STT 精度** — 让用户看见转录 + extraction 并 confirm
- **以姓名领头**（"张三 打电话 说下周回…"）— 抽取准确率 +20%
- **代码混合（code-switching）真实需求** — 不能只 zh、不能只 en

**2 周可落**: sherpa-onnx → 转录 → `POST /api/voice/extract` → LLM 出结构化 schema → upsert Interaction 行。

### Sprint 顺序推荐（**关键 insight**）

**Sprint 2（voice→structured）要在 Sprint 3（MCP）之前**。原因：

1. **Sprint 2 是 Sprint 3 的前置**：MCP 的 `ai_followup_draft` tool 需要 voice→structured 输出喂
2. **Sprint 1 大部分已上**（KIT + digest 都上线，**但 health score 被 a3b267c drop 了**）
3. **成本最低**：只加 LLM extraction 层，复用现有 STT 管道
4. **战略窗口**：weavine 是少数 "desktop-first + MCP" 组合；如果 MCP 错过 2026 标准，会被视为掉队

## 3. 产品成熟度（**6.5/10**）

### ✅ SOLID（10 项）

1. **KIT reminders** — 8 单测，`schedule_for_contact_tx` tx-safe，desktop+server 对称，cadence fallback 干净
2. **激活追踪 + device_key** — 匿名优先流完整，auth precedence（X-Device-Key → JWT → service key），IP 仅 hash
3. **Tauri 提醒调度** — Rust tokio sleep，桌面/移动 OS notification，startup catch-up
4. **Sync 引擎** — 11 trigger → sync_change_log，LWW on revision，26 migration 全部 additive
5. **OCR 名片流** — Tesseract chi_sim+chi_tra+eng，e2e 测过
6. **语音备忘** — SenseVoice Android + whisper.cpp 云兜底，single-flight semaphore，VAD
7. **日程 auto-log 互动** — server cron + desktop 等价，e2e 测过
8. **Contact graph** — `contact_relationship` 表，add/remove 端点，渲染
9. **路由注册模式** — `routes-config.tsx` 单一来源，30 routes
10. **Handler 错误处理** — 一致 `Result<Json<T>, (StatusCode, String)>`

### ⚠️ SKETCHY（7 项）

1. **每日 digest** — 客户端过滤 200 actions，**无 server 端点**，无 Shuffle
2. **Health score** — a3b267c **显式 drop** 了（roadmap 说的是 Sprint 1.1）
3. **Voice → 结构化笔记** — **未开始**。ASR OK，缺 LLM extraction
4. **`console.error` 噪音** — 4-8 处（avatar upload, voice, card image save, reminder poller）
5. **ContactsList 分页** — offset-based，**无 infinite scroll**，无虚拟滚动
6. **`Settings.tsx`** — **1026 行** monolith，内联 `catch`
7. **无统一 error toast** — 只有 `ReminderToast.tsx`
